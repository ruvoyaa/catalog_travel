# Draft Generation

## Назначение
Блок `Черновики описания` в админке используется для ускорения наполнения тура текстами. Это LLM-assisted workflow: система формирует черновой текст, а решение о применении остаётся за редактором.

## Где находится
- Откройте нужный тур в админке.
- На странице редактирования расположен блок `Черновики описания`.

## Что формируется
При генерации создаётся артефакт с двумя полями:
- `Краткое описание`
- `Полное описание`

Артефакт сохраняется отдельно и не изменяет тур автоматически.

## Пошаговая инструкция
1. Откройте тур в админке.
2. Убедитесь, что у тура уже заполнены хотя бы базовые данные:
   - название;
   - длительность;
   - категории;
   - при необходимости черновой контекст по маршруту.
3. В блоке `Черновики описания` нажмите `Сформировать черновик`.
4. Дождитесь появления нового блока черновика с датой генерации.
5. Просмотрите оба текста.
6. Если текст подходит, нажмите `Применить к туру`.
7. После применения проверьте поля описания и публичную карточку тура.

## Статусы черновика
- `Подготовлен` — текст сгенерирован, но ещё не применён.
- `Применён` — текст был записан в карточку тура.

## Рекомендуемый рабочий порядок
1. Сначала заполнить структуру тура.
2. Затем сгенерировать черновик.
3. После генерации вручную проверить и при необходимости отредактировать результат.
4. Только после этого публиковать тур.

## Практические замечания
- Draft generation ускоряет стартовое наполнение, но не заменяет редакторскую проверку.
- Если изменились название, длительность или позиционирование тура, лучше создать новый черновик.
- Если ручной текст уже качественный, AI-блок не обязан использоваться.

## Что проверить после применения
- Текст соответствует типу тура.
- Описание не противоречит маршруту, длительности и ценам.
- В карточке тура нет повторов, пустых формулировок и технических фраз.
