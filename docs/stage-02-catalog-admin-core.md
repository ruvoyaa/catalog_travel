# Stage 02 — Catalog And Admin Core

## Цель этапа

Реализовать core доменную и прикладную основу каталога туров и административной части.

## Что входит в этап

- доменная модель туров, категорий, медиа, маршрутов, дат и цен;
- миграции и базовая схема PostgreSQL;
- административный CRUD для туров;
- CRUD дат и цен;
- CRUD категорий или типов;
- управление фотоальбомом;
- управление статусами `draft` / `published`;
- публичный каталог;
- карточка тура;
- базовые фильтры.

## Что не входит в этап

- semantic search;
- embedding pipeline;
- LLM-генерация;
- расширенная SEO-оптимизация beyond basic correctness;
- сложные служебные dashboards.

## Ожидаемый результат

- администратор может полностью завести и опубликовать тур вручную;
- пользователь может видеть каталог и страницу тура;
- фильтры работают по согласованным базовым полям;
- маршрут отображается на Яндекс Карте.

## Основные риски

- неправильная граница между публичной карточкой и admin editing model;
- слишком слабая модель маршрута;
- неконсистентность нескольких вариантов дат и цен.

## Проверки

- миграции чисто выполняются;
- CRUD сценарии закрыты тестами или проверяемыми сценариями;
- draft/published поведение не ломает public catalog;
- карта и медиа корректно отображаются.

## Фактический статус

Stage 02 в текущем baseline закрыт как working core.

Что фактически реализовано:

- Laravel admin dashboard, CRUD туров и категорий;
- доменные сущности туров, дат и цен, изображений и маршрутов;
- public JSON API каталога и страницы тура;
- SSR frontend на Vike/Vue для каталога и страницы тура;
- базовые фильтры по тексту, категории и длительности;
- draft/published поведение для публичной части;
- inline validation feedback в админской форме тура;
- feature-тесты на admin workflow и public API.

Что важно зафиксировать перед Stage 03:

- Stage 02 не включает semantic search и LLM workflow;
- текущая модель тура и CRUD считаются опорным baseline для AI/search расширений;
- дальнейшие изменения Stage 03 не должны ломать существующий admin CRUD и public catalog contract.
