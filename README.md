# catalog_travel

Веб-приложение с публичным каталогом туров и административной частью без функционала бронирования.

## Стартовый baseline

- стек: Laravel / PHP;
- режим старта: анализ, затем разработка;
- ожидаемый масштаб: средний, но с усиленной документацией;
- frontend: Vue + Vike + Vite + Tailwind 4;
- database: PostgreSQL;
- infrastructure: monorepo + Docker.

## Цель

Сделать полноценный каталог туров с:

- публичным каталогом;
- карточкой тура;
- базовыми фильтрами;
- семантическим поиском;
- административной частью для управления турами, датами, ценами, медиа и публикацией;
- ручным запуском LLM-генерации тура.

## Границы на старте

- не придумывать архитектуру до изучения фактической задачи;
- не раздувать документацию сверх реальной пользы;
- разбить проект на 3-4 крупных этапа, без размазывания на мелкие стадии;
- сначала зафиксировать master-spec, границы и ТЗ этапов, потом переходить к коду.
- для stage-01 использовать monorepo skeleton с `apps/backend`, `apps/frontend` и Docker baseline.

## Что сейчас сознательно не делаем

- не добавляем функционал бронирования;
- не строим heavy-enterprise процесс сверх нужного;
- не начинаем прикладную разработку до завершения документационного foundation первого этапа.
